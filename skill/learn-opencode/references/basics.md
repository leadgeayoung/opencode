# 基础操作

## 10 大内置工具

| 工具 | 用途 | 要点 |
|------|------|------|
| **read** | 读取文件 | 默认 2000 行，大文件自动分段；支持图片/PDF base64 |
| **write** | 创建/覆盖文件 | 必须先读后写（安全机制）；写完后自动 LSP 诊断 |
| **edit** | 精确替换 | 9 层匹配策略；多处匹配需提供更多上下文或用 `replaceAll` |
| **bash** | 执行命令 | 默认 2 分钟超时；输出截断 2000 行/50KB |
| **grep** | 搜索内容 | 最多 100 条结果，支持正则 |
| **glob** | 搜索文件名 | 最多 100 条结果，支持通配符 |
| **Task** | 子 Agent 任务 | 复杂任务分解，独立 Session 隔离 |
| **WebFetch** | 获取网页 | URL 内容获取（text/markdown/html） |
| **TodoWrite** | 任务清单 | AI 自动使用，跟踪进度 |
| **Skill** | 加载专业知识 | 按需加载 |

核心原则：专用工具优于 bash 命令（有权限检查、智能容错、LSP 诊断）。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 切换 Agent（Build/Plan） |
| `Ctrl+X N` | 新建会话 |
| `Ctrl+X L` | 会话列表 |
| `Ctrl+X M` | 模型列表 |
| `Ctrl+X U` | 撤销 |
| `Ctrl+X R` | 重做 |
| `Ctrl+X Y` | 复制消息 |
| `Ctrl+X C` | 压缩上下文 |
| `Ctrl+T` | 切换思考深度 |
| `Ctrl+P` | 命令面板 |
| `Escape` | 中断 AI（按两次强制） |
| `Shift+Enter` | 换行（不发送） |
| `Ctrl+C` | 清空 / 关闭 / 退出（三态） |

Leader 键机制：`Ctrl+X`（默认）作为前缀键，按后松开再按字母键（类似 Vim Leader）。

Readline 风格：`Ctrl+A/E/K/U/W`、`Alt+B/F` 在输入框可用。

## 复制内容

- `Ctrl+X Y` 复制当前消息
- 选中文本自动支持复制
- 支持复制代码块、文件内容
